# 鲸跃

鲸跃是一个本地 DeepSeek Harness 插件，为网页端加一只游动的鲸鱼。

## 它提供什么

- 空白首页背后的鲸鱼画布；开启「在会话中自动出现」后也会出现在进行中的会话背景里，并按设定的间隔重播。每次出现（切换会话或按间隔）会按启用的填充样式（默认点阵与代码填充）顺序交替。点击会话空白区域可重播一次。
- 「深度求索中」左侧的鱼形图标：可用开关决定是否替换 DSH 默认的鲸尾图标；沿用首页同一条鱼的轮廓，图标颜色与状态文字颜色都可跟随主题或自定义，尺寸 8–28 px，状态文字字号 11–20 px（不改变行高与内边距），摆动幅度 50%–200%，可分别微调水平与垂直起始位置，提供四种动作预设；这些外观参数都在「实时预览」浮层里调整，页面保留模拟真实会话状态行的预览（含分隔线与行高）。
- 设置分区「设置 › 鲸跃」，页面只保留预览画布、播放分组和「实时预览」入口；所有外观控制都在实时预览浮层里，用「背景」「任务图标」两个标签组织。
- 设置页头部显示当前版本与「检查更新」：并行查询 GitHub Release API 与 jsDelivr 标签镜像，优先采用 Release 结果、镜像兜底（不受 GitHub API 配额限制）；发现新版本时给出「升级」按钮，把发布标签解析成对应提交后交给 DSH 插件管理器就地替换（先卸载再安装固定到该提交的版本，失败会自动恢复到原版本），升级完成后需要重启 `dsh web` 才会加载新版本。插件管理器不可用或检查失败（限流、网络、超时）时保留发布页链接兜底。

## 使用

1. 在网页端打开 **插件**，选择 **添加插件**，填入目录 `C:\Users\Y\Desktop\dsh project\whale-leap`。
2. 重启一次 `dsh web`：Host 只在启动时加载包与设置 schema；重启后刷新页面。
3. 打开「设置 › 鲸跃」，修改即时生效。

## 行为

- 设置页只保留播放控制、每个标签页的预览画布和一个「实时预览」入口；外观控制全部在实时预览浮层里，用「背景」「任务图标」两个标签组织。页头、选项卡与预览作为一整块吸顶并保持间距，预览底部留白。
- 实时预览：点击后设置窗口隐藏，真实会话里持续循环播放鲸鱼；在空白首页上会先铺出与真实会话一致的模拟版面（演示对话、底部输入框与「深度求索中」状态行），没有会话时也能对照真实宽度调参。浮层的「背景」标签包含颜色、背景大小（50%–150%）、水平/垂直起始位置（各 −200 到 +200 px）、墨色浓度（10%–100%，60% 保持原稿观感，100% 压成纯黑）和填充样式；「任务图标」标签包含替换开关、图标颜色、文字颜色、图标大小（8–28 px）、文字大小（11–20 px，不改变行高与内边距）、水平/垂直位置（各 −12 到 +12 px）、动画（游动/探索/首页游动/左右轻摆）与摆动幅度（50%–200%）。Esc 或「返回设置」恢复窗口。
- 「随机位置」开启后每次出现都换一个位置；再打开「多条鲸鱼」时一次画出 2–3 条鲸鱼：每条落在不同位置，绘制范围之间留出足够间隔，不会重叠或挤在一起。「远近墨色」开启时越远的鲸鱼墨色越浅（最近 100%，最远约 55%），关闭后所有鲸鱼用同一浓度；「出现时机」可选「同时出现」或「各自随机时间」；「大小范围」用两个滑杆设置多条鲸鱼从最远到最近的尺寸（20%–100%，默认 34%–68%）。
- 填充样式是并排的多选按钮（点阵、代码填充、字符画、二进制、线条）；启用的样式按顺序交替出现，至少保留一项；自定义文字颜色会同时重混扫光高光色，让移动渐变跟随所选颜色。
- 「在会话中自动出现」决定开始对话后是否自行出现；「切换会话时立即出现」决定进入会话时立刻播放还是等下一个间隔；间隔 5–300 秒。
- 预览画布按当前设置循环播放，右下角「重播」可立即重放；设置变更也会自动重播。
- 任务图标预览模拟真实会话状态行（0.5px 分隔线、28px 行高、蓝调状态文字）；文字颜色会同时重混移动渐变的高光色。
- 摆动幅度只作用于游动、探索与左右轻摆；「首页游动」保持首页原样。
- 代码文字填充的字号随背景场景宽度等比缩放，预览区与窄栏位中的文字比例与真实背景一致。
- 减少动态效果时所有播放与摆动停止，图标静止。
- 背景画布后备缓冲区上限 500 万像素，并在布局之间复用。

## 限制

- 仅网页端，需要 `ui-conversation`、`ui-chat`、`ui-settings` 客户端包。
- 设置是工作区级的，命名空间为 `whale-leap`。
- 内置品牌包不再绘制任何鲸鱼，只提供侧栏品牌图形，因此不会与本插件重叠；声明了 `conversation.chat.running.mark` 的构建通过插槽替换图标，未声明的官方构建由 DOM 适配器挂载同一图标并隐藏原图标。
- 鲸鱼帧图集（`assets/breach-atlas.webp`）在 MIT 许可下随包分发，构建时内嵌为 data URL 写入 `lib/client.js`；因此不需要 Host 路由、离线可用，桌面版（品牌包在 asar 内）也能绘制。
- 设置页跟随 DeepSeek Harness 的界面语言（中文、English、日本語、Español、Français、Deutsch、Русский、Português）。

## 构建

```powershell
pnpm install
pnpm run build
```

生成 `lib/client.js`（ModuleLoader 产物，帧图以 webp data URL 内嵌）。Host 半部分（`index.js`）只从运行中的 profile 引入 `@deepseek-ai/schemastery` 并注册设置页。
