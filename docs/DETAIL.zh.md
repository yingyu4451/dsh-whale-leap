# 鲸跃

鲸跃是一个本地 DeepSeek Harness 插件，为网页端加一只游动的鲸鱼。

## 它提供什么

- 空白首页背后的鲸鱼画布；开启「在会话中自动出现」后也会出现在进行中的会话背景里，并按设定的间隔重播。每次出现（切换会话或按间隔）会在点阵与代码文字两种画面之间交替。点击会话空白区域可重播一次。
- 「深度求索中」左侧的鱼形图标：可用开关决定是否替换 DSH 默认的鲸尾图标；沿用首页同一条鱼的轮廓，图标颜色与状态文字颜色都可跟随主题或自定义，尺寸 8–28 px，状态文字字号 11–20 px（不改变行高与内边距），摆动幅度 50%–200%，可分别微调水平与垂直起始位置，提供四种动作预设，以及模拟真实会话状态行的实时预览（含分隔线与行高），预览右下角可重播。
- 设置分区「设置 › 鲸跃」，分为「背景」和「任务图标」两个标签页；标签页内按「外观」「播放」「显示」「动作」分组。
- 设置页头部显示当前版本与「检查更新」：以 GitHub 为准，先读最新 Release（没有时退回标签），有新版本时给出链接；尚无发布或检查失败时会明确提示具体原因（限流、网络、超时）并给出发布页链接。

## 使用

1. 在网页端打开 **插件**，选择 **添加插件**，填入目录 `C:\Users\Y\Desktop\dsh project\whale-leap`。
2. 重启一次 `dsh web`：Host 只在启动时加载包与设置 schema；重启后刷新页面。
3. 打开「设置 › 鲸跃」，修改即时生效。

## 行为

- 颜色：跟随主题文字色，或自定义墨色。背景大小 50%–150%；墨色浓度 10%–100%——图集本身偏淡，60% 保持原稿观感，100% 把淡点压成纯黑。出现画面可选交替（圆点+代码，默认）、圆点、代码文字、字符画、二进制或线条。
- 「在会话中自动出现」决定开始对话后是否自行出现；「切换会话时立即出现」决定进入会话时立刻播放还是等下一个间隔；间隔 5–300 秒。
- 设置页把控制项按主题分组：上方是小标题，下方是承载各行的卡片。
- 任务图标：**替换任务状态图标** 开关决定是否用小鱼替换默认的鲸尾；可选游动、探索、首页游动、左右轻摆，每张卡片播放各自的动作；上方预览区模拟真实会话状态行（0.5px 分隔线、28px 行高、蓝调文字），向下滚动设置时保持完整高度、吸顶在页头与选项卡下方，按当前设置的精确像素显示图标，旁边显示「深度求索中」状态文字（跟随界面语言），拖动滑块即可实时预览；选中项有文字徽标。文字颜色的自定义会同时重混扫光高光色，让移动渐变跟随所选颜色。
- 摆动幅度 50%–200% 只缩放游动、探索与左右轻摆的水平幅度；「首页游动」保持首页原样。**文字大小**（11–20 px）只调整「深度求索中」这一行文字的字号，行高与内边距保持不变。**水平位置**与**垂直位置**分别微调图标的起始点，各自 −12 到 +12 px。
- 代码文字填充的字号随背景场景宽度等比缩放，预览区与窄栏位中的文字比例与真实背景一致。
- 减少动态效果时所有播放与摆动停止，图标静止。
- 背景画布后备缓冲区上限 500 万像素，并在布局之间复用。

## 限制

- 仅网页端，需要 `ui-conversation`、`ui-chat`、`ui-settings` 客户端包。
- 设置是工作区级的，命名空间为 `whale-leap`。
- 内置品牌包不再绘制任何鲸鱼，只提供侧栏品牌图形，因此不会与本插件重叠；声明了 `conversation.chat.running.mark` 的构建通过插槽替换图标，未声明的官方构建由 DOM 适配器挂载同一图标并隐藏原图标。
- 鲸鱼帧图集（`assets/breach-atlas.webp`）在 MIT 许可下随包分发，构建时内嵌为 data URL 写入 `lib/client.js`；因此不需要 Host 路由、离线可用，桌面版（品牌包在 asar 内）也能绘制。
- 设置页跟随 DeepSeek Harness 的界面语言（中文、English、日本語、Español、Français、Deutsch、Русский、Português）。

## 构建

```powershell
pnpm install
pnpm run build
```

生成 `lib/client.js`（ModuleLoader 产物，帧图以 webp data URL 内嵌）。Host 半部分（`index.js`）只从运行中的 profile 引入 `@deepseek-ai/schemastery` 并注册设置页。
