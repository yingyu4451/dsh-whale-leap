# 鲸跃

鲸跃是一个本地 DeepSeek Harness 插件，为网页端加一只游动的鲸鱼。

## 它提供什么

- 空白首页背后的鲸鱼画布；开启「在会话中自动出现」后也会出现在进行中的会话背景里，并按设定的间隔重播。点击会话空白区域可重播一次。
- 「深度求索中」左侧的鱼形图标：沿用首页同一条鱼的轮廓，尺寸 8–28 px，提供四种动作预设。
- 设置分区「设置 › 鲸跃」，分为「背景」和「任务图标」两个标签页。

## 使用

1. 在网页端打开 **插件**，选择 **添加插件**，填入目录 `C:\Users\Y\Desktop\dsh project\whale-leap`。
2. 重启一次 `dsh web`：Host 只在启动时加载包与设置 schema；重启后刷新页面。
3. 打开「设置 › 鲸跃」，修改即时生效。

## 行为

- 颜色：跟随主题文字色，或自定义墨色。背景大小 50%–150%；墨色浓度 10%–100%——图集本身偏淡，60% 保持原稿观感，100% 把淡点压成纯黑。
- 「在会话中自动出现」决定开始对话后是否自行出现；「切换会话时立即出现」决定进入会话时立刻播放还是等下一个间隔；间隔 5–300 秒。
- 任务图标可选游动、探索、首页游动、左右轻摆；每张卡片播放各自的动作，选中项有文字徽标。
- 减少动态效果时所有播放与摆动停止，图标静止。
- 背景画布后备缓冲区上限 500 万像素，并在布局之间复用。

## 限制

- 仅网页端，需要 `ui-conversation`、`ui-chat`、`ui-settings` 客户端包。
- 设置是工作区级的，命名空间为 `whale-leap`。
- 内置品牌包不再绘制任何鲸鱼，只提供侧栏品牌图形，因此不会与本插件重叠；需要声明 `conversation.chat.running.mark` 的 DSH 构建。
- 鲸鱼素材来自 DeepSeek Harness 品牌资源，仅供本地插件使用。

## 构建

```powershell
pnpm install
pnpm run build
```

生成 `lib/client.js`（ModuleLoader 产物，图集内嵌为 data URL）。Host 半部分是普通 ESM（`index.js`），从运行中的 profile 引入 `@deepseek-ai/schemastery`。
